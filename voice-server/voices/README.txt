Legg ekstra stemmeprofiler her som .wav-filer.

Filnavnet blir navnet på stemmen i programmet, for eksempel:
  rolig.wav      -> "Rolig"
  energisk.wav   -> "Energisk"

Bruk 20-30 sekunder ren tale, én person, uten musikk eller støy.
Programmet kan laste inn stemmene på nytt uten å starte TTS-serveren.
